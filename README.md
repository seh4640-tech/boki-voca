# 수능 영단어 30일

수능 필수 영단어를 30일 동안 외우는 웹앱입니다.

- Day 1~30 (기본 → 실력 → 고난도), 1,290단어
- 카드로 외우기 (탭하면 뜻, 발음 자동 재생)
- 4지선다 퀴즈 (영→뜻 / 뜻→영 / 섞어서)
- 오답노트 (두 번 맞히면 빠짐)
- 연속 학습일, 최근 4주 기록
- 홈 화면에 추가하면 앱처럼 사용 (오프라인 지원)

학습 기록은 각 기기 브라우저(localStorage)에 저장됩니다.
단어를 고치려면 `words.js`의 `[단어, 품사, 뜻]`을 수정하면 됩니다.
빌드 과정 없는 정적 사이트라 Vercel에서 그대로 배포됩니다.
