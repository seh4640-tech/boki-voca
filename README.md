# 보키랑 영단어 🦉

중학~수능 영단어(약 2,000개)를 **간격 반복**으로 오래 기억하는 암기 웹앱입니다.

- 처음 화면에서 공부할 사람 선택 (홍설아 · 홍연아, 추가 가능) — 기록은 사람마다 따로 저장
- 오늘의 미션: 다시 볼 단어 + 새 단어(기본 하루 10개)
- 단어 정원: 맞힐수록 🌰 씨앗 → 🌱 새싹 → 🌿 무럭무럭 → 🌳 내 거!로 자라고, 잊어버릴 때쯤 다시 나옴
- 놀면서 외우기: 카드 넘기기, 뜻 고르기, 영어 고르기, 듣고 고르기, 철자 쓰기(힌트), 짝 맞추기
- 레벨·별(⭐)·연속 정답·스티커 모으기·연속 출석
- 홈 화면에 추가하면 앱처럼 사용 (오프라인 지원)

단어는 `words.js`의 `[단어, 품사, 뜻, 단계]`를 고치면 됩니다. 단계: 0 중학 · 1 고등 기본 · 2 수능 실력 · 3 수능 고난도.
빌드 없는 정적 사이트라 Vercel에서 그대로 배포됩니다.
